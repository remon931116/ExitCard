# ExitCard 街頭海報 UI 改版紀錄

## 實作範圍與頁面盤點

- `Web/index.html`：唯一網站頁面。依原順序包含品牌標題、月份／週次導覽、課程表單／清單、固定與一次性提醒表單／清單、硬體同步及 400×300 電子紙預覽。
- `tku-connector/popup.html`：匯入擴充套件彈出頁。保留讀取、套用、狀態文字與 JSON 結果。
- 原專案沒有路由框架、套件管理設定、深色模式、彈窗／抽屜、排序表格或既有測試工具；沒有新增這些介面。
- `Web/script.js`、`tku-connector/popup.js`、manifest、localStorage schema、學校課表擷取與硬體同步協定皆未修改。

## 設計規格與實際取捨

| Token | 值 | 用途 |
|---|---|---|
| paper | #F3EBDD | 紙色背景 |
| surface | #FFFCF5 | 卡片、欄位、反白文字 |
| ink | #191919 | 主要文字、外框、硬邊陰影 |
| muted | #59534B | 輔助文字、placeholder |
| brand | #A83226 | 主操作、日期選取、展示標題 |
| brand-hover | #8C281F | 主操作 hover |
| accent | #F28A36 | 標題裝飾、次要控制 hover |
| disabled | #D9D0C2 | 停用背景 |

- 主頁的標題黑色底與橘色星芒由偽元素繪製；不新增可聚焦節點，不增加標題盒子高度。每個標題區最多兩種裝飾，裝飾不接收滑鼠事件。
- 品牌 ExitCard 保留原本 Arial 字重與字型，避免改變標誌外觀及整頁垂直位置。Today／Reminder 使用本機 Impact 的原生粗窄字形（400，避免瀏覽器合成粗體），保留原標題高度；字型不可用時使用 Arial Narrow／Arial。
- 保留原本表單字級、padding、寬高、600px 斷點與 DOM 順序；用內嵌邊框及陰影建立厚度，不加大元件。
- 課程／提醒列使用位於既有外邊距的 2px 黑框、6px 圓角與 4px 硬邊陰影。長字串可換行，刪除控制不被擠出。
- 日期底線與既有選取字重保留，再增加磚紅底色。主要按鈕 4px 圓角，Hover／Pressed 不移動元件。
- 焦點使用米白外框與炭黑外環；停用保留可讀文字並排除 Hover。過場 120ms，尊重 reduced-motion；支援 forced-colors 的輪廓回退。
- 擴充套件單獨打包，因此 popup.css 保留同一套色票的本地副本，不引用套件範圍外的 Web 資源。
- 所有資產皆使用現有字型／CSS；沒有新增網路字型、圖片依賴或框架。

### 行動版的兩項必要修正

基準版在 360px、390px 已有水平溢出。本次只調整：

1. 七個日期保留同一列，縮小間距以讓右箭頭留在內容區，點擊區大小不變。
2. 預覽以 CSS 等比例縮小到容器寬度；canvas 內部仍為 400×300，bitmap 完全相同。

除此以外，五個測試寬度下的標題、表單、按鈕與操作區 x／y／width／height 均與基準一致。原本提醒表單的緊密排列、原生 alert、日期 span 的鍵盤行為保持不變；本次未重做 UX 或宣稱完成全站無障礙改造。

## 截圖與重跑

- 開啟本目錄 `index.html`，可選取五種寬度或擴充套件，並排查看改版前後。
- `before/` 保存原版截圖、量測及 CSS；`after/` 保存最終截圖、量測與狀態畫面。
- 預覽截圖為了比較 bitmap，會呼叫既有 drawExitCard()；正式頁面的繪圖時機未更動，因此初次載入時仍依原程式顯示空白預覽。
- 本機具備 Node、Playwright 及 Chrome 時，在專案根目錄執行 `node tools/ui-check.cjs after`。若 Playwright 位於其他位置，先設定 NODE_PATH 至對應 node_modules。
- 請保留 before 基準，正常重跑只使用 after；before 模式僅用於刻意建立新基準。
- 未以真實 Chrome extension 安裝流程、淡江登入帳號或實體 ESP32 進行端到端驗證。Web 與 popup 的真實 JavaScript 皆未更動。
